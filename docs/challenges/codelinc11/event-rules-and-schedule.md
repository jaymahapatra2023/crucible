# codeLinc 11 — Rules and schedule

Lincoln Financial Group · 3–4 October 2026 · Greensboro, NC

## Two critical rules

1. You can leave at any time, but there is no re-entrance once you do.
2. Enjoy yourself, watch the clock, take breaks and don't hesitate to ask for help.

## Teams

- Teams are three to eight people.
- Each team chooses one path: Path 1, Dental Benefits Optimizer, or Path 2, Life Insurance Needs
  Analyzer.
- After choosing a team name and a room, register the team. Team registration is the record the
  organisers judge from.
- Coaches and mentors are reached through the codeLinc 11 Discord server.

## Submissions

- Each team submits the repository it built during the event, with a README that says how to
  build and start it, and the design documentation it kept while building.
- Work is expected to have been built during the event. Repositories are checked for how they
  were built up over the 24 hours.
- Building with AWS is optional. There are no event-provided AWS credits; a team that creates its
  own AWS account should set a $0 budget alert and stop resources after the demo.
- Do not commit credentials, API keys or personal data to the repository.

## Presentations and judging

Presentations are Sunday 10:00–12:00. Judges assess the repository, the demo, the README and the
design documentation. Prizes are awarded at 12:45.
